NOTES
════════════════════════════════════════════
- Replace 6033593 with your actual test sub-account ID
- Server: cd chatbot_web && python app.py  (runs on port 8000)
- Swagger UI: http://localhost:8000/docs
- Logs: chatbot_web/logs/log.txt
- Session TTL: 900s (15 min) — configurable via SESSION_TTL_SECONDS in config/.env
- Gateway: disabled by default (ENABLE_AGENTCORE_GATEWAY=false) — all calls use direct HTTP
- Environment: ENVIRONMENT=local_test — enables direct HTTP fallback
